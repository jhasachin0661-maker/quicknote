# QuickNote 📝

> A simple, lightweight, backend-free, and database-free note-taking web application. Everything runs directly in your browser and automatically saves to local storage!

---

## ⚡ Super Simple: No Backend, No Database Needed!

- **100% Client-Side**: Notes are automatically saved directly into your browser's `localStorage`.
- **Instant Autosave**: Just type — changes save as you type without delay.
- **Persistent**: Notes stay saved even if you refresh or close the browser.
- **Search & Filters**:
  - Live search across titles and content.
  - Pin important notes to the top.
  - Mark notes with a Star (Favorites).
  - Add and filter by `#tags`.
  - Move to Trash, Restore, or Permanently Delete.
- **Themes**: Switch between Light and Dark mode with 1 click.
- **Zero Config**: No Python server to run, no database to configure.

---

## 🚀 How to Run (1 Step)

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser and start typing!
